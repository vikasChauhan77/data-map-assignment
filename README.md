# data-map-assignment

Application built using VueJs as frontend and Node/Express as backend. This application takes a sample data (currently in local json file sample.json) and visualizes it in browser using **D3.js**.

## Instructions
1. After cloning, move to project and run **npm install**
2. Run **npm run server** to start the server. Server will be started on localhost:3000/data with json contents
4. Run **npm run dev** to start the application.
